# NuguCall Server

Server component of NuguCall, a call connection application based on multimodal interaction.

## Related repository

- [NuguCall Android](https://github.com/SamoSpri/NugucallAndroid)

## Source layout

- [nugucallserver](nugucallserver) contains the server implementation.
- [nugucall-web.js](nugucall-web.js) and [nugucall.css](nugucall.css) contain browser-side behavior and styles.
- [contentsviewer.html](contentsviewer.html) and [recordsviewer.html](recordsviewer.html) provide content and record views.

Review the server source and its configuration before running it alongside the Android client. A standalone deployment configuration is not included.
